# Ultron A.I. v2

A voice-reactive 3D neural blob desktop app inspired by Ultron.

## Live Demo

**[Click here to view](https://londhepratik2008-maker.github.io/ultron-v2/index.html)**

## Features

- Animated 3D neural blob with custom GLSL shaders
- 5000+ streaming particles & orbital rings
- Voice recognition & speech synthesis
- 4 themes — Ultraviolet, Cyberpunk, Matrix, Fire & Ice
- Customizable bloom, noise, particles, and voice settings
- 8 camera presets with zoom controls
- Click the blob to trigger ripple effects
- Built with Python + pywebview + Three.js
